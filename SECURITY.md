# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of Mermaid Content Blocks.

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |
| Earlier versions | No |

## Reporting a Vulnerability

Please do not disclose suspected vulnerabilities in a public issue, discussion, or pull request.

1. Open the repository's [Security tab](https://github.com/Monotoba/Mermaid-WP-Block/security).
2. Select **Report a vulnerability** if GitHub offers that option.
3. Include the affected version, reproduction steps, impact, and any suggested remediation.

If private vulnerability reporting is not available, open a public issue that contains only a request for a private contact channel. Do not include exploit steps, sensitive data, or other vulnerability details in that issue.

You should receive an acknowledgment within seven days. After reviewing the report, the maintainer will share the next steps and coordinate disclosure when appropriate.

## Scope

Reports about the plugin's PHP, JavaScript, block rendering, data handling, or packaged release are in scope. Vulnerabilities in WordPress, browsers, Mermaid.js, or other third-party services should also be reported to the relevant upstream project.
